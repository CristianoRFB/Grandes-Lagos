# Escopo — C001/P00

## Resultado

Bootstrap reproduzível do GL Operations com backend Spring Boot, frontend
React/TypeScript, PostgreSQL, Flyway, Docker Compose, scripts canônicos e um job
GitHub Actions `p00`, mantendo o sistema em S0 até todos os gates serem provados.

## Aceite

- AC-001..AC-022 são avaliados individualmente com evidência real.
- S0 só avança para S1 quando todos estiverem PASS.
- P01 permanece bloqueado e só pode ser elegível em change separado após S1.

## Limites

Sem domínio, Identity/RBAC, autenticação, JPA/ORM, tabelas de negócio, eventos,
outbox, integrações ERP/eSolution, TanStack Query, staging/prod ou dados reais.
A baseline 00–30 permanece externa e congelada.
